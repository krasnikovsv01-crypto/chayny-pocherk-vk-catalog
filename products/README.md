# Изображения товаров «Чайный почерк»

Сюда нужно загрузить 16 JPG из папки `products` предоставленного архива. Имена файлов не менять. Формат: JPG, 1024×1024.

Все изображения художественные иллюстрации, не фотографии конкретных партий чая. Перед фактической продажей уточнить внешний вид и состав товаров и по возможности заменить на достоверные фотографии.

Не запускать импорт общего YML до завершения загрузки фотографий и проверки цен/наличия.
